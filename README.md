## Tervehdys!

Täältä löytyy opintojeni aikana ja niiden jälkeen tehtyjä projekteja ja koodaustehtäviä. Olen valinnut tähän repositioon muutaman projektin, jotka näyttävät minkälaisia teknologioita olen käyttänyt.
